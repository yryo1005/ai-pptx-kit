# スライド作成に関する規約
本リポジトリは，AIによるスライドの作成・改訂に用いる共通規約とテンプレートを提供する．

---

# スライドのテンプレート
- スライドの作成が依頼された場合，`@.ai/ai-pptx-kit\templates` 内のpptxファイル等をプロジェクトのルートにコピーし，これを編集してスライドを作成してください
- この際，ファイル名はスライドの内容に応じ適時変更してください

| ファイル名 | 内容 |
| :--- | :--- |
| `templates/reserch.pptx` | 研究結果を発表する際のスライド |
| `templates/business.pptx` | ビジネスの提案や報告のスライド |

# スライド作成に関する共通規約

- 1スライド1メッセージを原則とする．
- スライド内の情報量を過度に増やさない．
- 見出しだけでスライドの主張が理解できるようにする．
- 長文の段落をそのままスライドへ配置しない．
- 図表を使用する場合，図表だけで意味が伝わるようにする．
- 図表には必要に応じてタイトル，軸ラベル，凡例等を付ける．
- 重要な数値や結論は視覚的に識別できるようにする．
- フォント，文字サイズ，余白，色等はテンプレートに従う．
- `.pptx` のテンプレートそのもののデザインをAIが独自に変更しない．

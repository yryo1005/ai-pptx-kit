# スライド作成に関する共通規約

- 1スライド1メッセージを原則とする．
- スライド内の情報量を過度に増やさない．
- 見出しだけでスライドの主張が理解できるようにする．
- 長文の段落をそのままスライドへ配置しない．
- 図表を使用する場合，図表だけで意味が伝わるようにする．
- 図表には必要に応じてタイトル，軸ラベル，凡例等を付ける．
- 重要な数値や結論は視覚的に識別できるようにする．
- フォント，文字サイズ，余白，色等はテンプレートに従う．
- `.pptx` のテンプレートそのもののデザインをAIが独自に変更しない．

## 1. 数式
数式はPowerPointのネイティブな数式オブジェクトとして作成する．
数式を画像として貼り付けることは禁止する．
通常のテキストボックスにLaTeXを文字列として記述することも禁止する．
数式はLaTeXを入力形式として使用し，LaTeXからOffice Math Markup Language（OMML）へ変換した後，PPTX内部にOMMLとして挿入する．

```text
\[
f(\mathbf{x}) =
\frac{1}{N}
\sum_{i=1}^{N}
\ell_i(\mathbf{x})
\]
```

この数式は画像ではなく，PowerPoint上で編集可能なネイティブ数式として保存する．
文章中の数式や，式中の変数を説明する際にも必ず上記のように実施する．

## 2. 図・グラフ
スライドの内容を視覚的に理解するために有効な場合は，適切な図，模式図，グラフ等を配置する．
ただし，情報量を増やすこと自体を目的として不要な図を追加しない．
図はスライドの主張を補足する目的で使用し，本文だけでは理解しにくい概念や処理フロー，モデル構造，アルゴリズム等については積極的に図式化する．

## 3. 文字サイズ
文字サイズはスライドの用途と情報量に応じて設定する．
本文は原則として十分な大きさを確保し，1枚のスライドに大量の文章を詰め込まない．
タイトル，見出し，本文，注釈等で文字サイズに明確な階層を設ける．
具体的な文字サイズが指示されている場合は，その指定を優先する．

## 4. レイアウト
1枚のスライドに過剰な情報を配置しない．
文章，図，表，数式等を適切に組み合わせ，スライド単体で内容の論理構造を把握できるようにする．
同じ種類の情報については，スライド間で配置やデザインを可能な限り統一する．
テキストボックス中で文章を改行する場合は，単語の途中で改行しないように注意する．

# スタイルチェック
pptxファイルの生成および編集にLibreOfficeを使用しない．
PowerPoint互換のOOXMLを直接生成・編集する．

pptxファイルの作成後，`@.ai/ai-pptx-kit/scripts/convert_to_pdf.sh <pptxのパス>`を実行してPDF化し，
スタイルを確認する．

## PPTX→PDF変換の方式
- LibreOfficeによるPDF変換では，OMML（PowerPointネイティブの数式オブジェクト）等が正しく
  レンダリングされず，数式・記号が消失する場合がある．
- 実行環境がWSLであり，かつWindows側にPowerPointが実際にインストールされている場合，
  `convert_to_pdf.sh`は自動的にPowerPoint本体のCOMオートメーション（`convert_to_pdf.ps1`）を
  用いてPDFを生成する．編集時と同じ見た目でレンダリングされるため，こちらを優先する．
- WSLでない場合，PowerPointが利用できない場合，またはPowerPoint経由の変換が失敗した場合は，
  LibreOfficeへ自動的にフォールバックする．この場合，標準エラー出力にその旨が表示されるため，
  生成されたPDFに数式・記号の消失や文字化けがないか，必ず目視で確認すること．
- `convert_to_pdf.sh`を直接実行できない環境（Windows側のPowerShell実行自体が失敗する等）では，
  スクリプトが自動的にLibreOfficeへフォールバックするため，個別に判定作業を行う必要はない．

# AIエージェントとの連携
本プロジェクトでは，`.ai/ai-agent/`のAIエージェントが，作成したスライドの内容をGemini API
へPDFとして入力し，スタイルの崩れや視認性の低下箇所の指摘を検討する場合がある．
`ai-pptx-kit`自体の役割は，スライドの作成規約とテンプレートの提供であり，AIエージェントの
役割（次の指示の検討）とは異なるため，両者を混同しない．

- pptxを編集した場合は，上記「スタイルチェック」の手順で生成したPDFを最新の状態でリポジトリ内に
  保持する．
- `.reports/report_{k:03}.md`には，作成したスライドの対象（発表時間，対象聴衆等）や，未解決の
  指摘事項を明記し，AIエージェントが次の指示を検討する際に参照できるようにする．
